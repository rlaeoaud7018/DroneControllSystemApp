# web-dashboard

지도 + 카메라 마커 + 그래프 + 라이브 뷰를 보여주는 PC 관제 화면.
사용자가 제시한 레퍼런스 스크린샷 3장(지도+카메라 카드 그리드, 아코디언형 통계 패널, 둘을 합친 전체 화면)의 레이아웃을 그대로 따라감.

**실행 위치**: 별도 서버 없이 backend-api(Spring Boot)의 정적 리소스로 같이 서빙됨.
`backend-api/src/main/resources/static/` 아래에 있고, backend-api를 띄우면 `http://localhost:8080/backend-api/index.html`로 바로 접근 가능 (CORS 걱정 없음, 같은 origin).

## 구현 완료 (실제 브라우저로 동작 확인)

- **로그인 게이트**: 페이지 열면 `GET /api/v1/users/me`로 세션 확인 → 401이면 로그인/회원가입 오버레이, PRE_USER면 "승인 대기 중" 화면, 그 외엔 바로 대시보드
- **상단바**: 제목 + 메인 탭(대시보드/통계·구역 비교/이벤트 로그) + 조작 힌트 문구 + 혼잡 단계 범례(정상/주의/위험 구역 수) + 로그인한 사용자 이름·권한 배지·로그아웃 버튼
- **지역 필터**: 시/구/동 3단 계층 드롭다운(`GET /api/v1/regions?parentId=`로 단계별 로드), 선택한 동(dongId) 기준으로 구역 목록을 불러옴. 최상위 항목이 이미 DONG 레벨(상위 계층이 없는 경우)이면 하위 드롭다운 없이 바로 적용되도록 일반화해둠
- **대시보드 탭**:
  - 상단에 드래그로 높이 조절 가능한 구글 지도. 구역마다 상태색(정상/주의/위험) 카메라 아이콘 마커 + 진행 중 이벤트 수 배지, 마커 클릭 시 해당 캠 확대 모달. 지도 빈 곳 우클릭하면 새 구역+카메라를 바로 등록 가능
  - 좌측 하단 "▶ 통계" 버튼으로 통계 패널을 오버레이 사이드바로 열고 닫음 (아래 통계 패널 참고)
  - 지도 아래 카메라 카드 그리드: 구역별로 체크박스/상태뱃지(위험·주의)/위치(구·동·면적)/실시간 썸네일(또는 "영상 없음")/상태·인원·이벤트 수/액션버튼(영상 올리기·분석 시작 또는 다시 분석·중단) 표시. 캠이 없는 구역은 "카메라 등록" 버튼만 있는 카드로 표시
  - "전체 펼치기"/"4분할 보기" 토글 — 4분할은 체크된 카메라(없으면 앞의 4개)만 크게 보여줌
  - 카드를 클릭(버튼/체크박스 제외)하면 확대 모달이 뜨고 인원/밀집도/체류시간 숫자 + 1분 단위 꺾은선 그래프(`GET /api/v1/zones/{id}/stats`) + RUNNING이면 analysis-server MJPEG 라이브 뷰(탐지 박스 포함) 표시
- **통계 패널** (대시보드 탭의 오버레이 사이드바 / "통계·구역 비교" 탭에서는 같은 내용을 전체 화면으로 재사용): 현재인원/이벤트/혼잡단계 전환 가능한 도넛차트, 요약(카메라 수·총 인원·평균 밀집도·가장 혼잡한 구역·오늘 이벤트·최대 인원) 카드, 아코디언(인원수·밀집도 / 유입·유출(추정) / **이동 분석(속도·방향)** / 혼잡 정도·기준 설정(관리자는 `PUT /api/v1/zones/{id}/thresholds`로 직접 수정 가능) / 피크 시간 TOP3·증감 추세 / 비정상 인원 변동) — 전부 실데이터 기반, 새로고침 주기(5·10·30초) 선택 가능
- **이벤트 로그 탭**: `GET /api/v1/events` 목록, 메인 탭에 미해결 건수 빨간 배지(5초마다 갱신). 관리자(ADMIN/SUPER_ADMIN)만 "확인"/"조치완료" 버튼 + 메모 입력, `PATCH /api/v1/events/{id}`로 처리. 일반 회원은 조회만(서버에서도 403으로 막힘)

로그인 → 지역 필터 → 지도/카드 → 확대 모달 → 통계 아코디언 → 이벤트 확인/조치완료 → 로그아웃까지 전부 실제 Chrome에서 클릭해서 검증 완료.

## 구글 지도 API 키 — 설정 완료

웹용 키를 발급받아 `index.html`에 적용 완료 (Maps JavaScript API, 애플리케이션 제한 "웹사이트" + `http://localhost:8080/*`로 제한해둠 — 다른 도메인에서는 이 키로 지도를 못 띄움).
지도 스타일은 대시보드 다크 테마에 맞춘 커스텀 스타일(POI·대중교통 라벨 숨김, 도로/라벨 색상 조정)을 적용함.

다른 호스트/포트로 배포하게 되면 Cloud Console에서 웹사이트 제한 목록에 그 주소를 추가해야 한다.

## 발견했던 버그

**카메라 여러 대를 동시에 RUNNING으로 띄우면 라이브 썸네일이 전부 멈춤**: 원인은 `app.js`의 `renderCameraGrid()`/`renderCameraDetail()`이 폴링(기본 10초)마다 `innerHTML`을 통째로 다시 그리면서 `<img src=".../live">`도 매번 새로 만들었던 것. 화면에서 사라진 이전 `<img>`의 MJPEG 스트리밍 연결이 바로 끊기지 않고 쌓이다가 브라우저의 호스트당 동시 연결 수 제한(보통 6개)에 걸려 버렸고, 그 뒤로는 새 이미지 요청이 전부 "대기" 상태로 멈춰서 영상이 하나도 안 보였다 (로딩도 에러도 안 뜨는 상태라 원인 찾기 까다로웠음 — curl로 analysis-server 스트림 자체는 정상임을 먼저 확인하고, 네트워크 탭에서 같은 요청이 계속 pending으로 쌓이는 걸 보고서야 연결 수 제한임을 특정함). 카메라 구성(아이디·상태)이 이전 렌더와 똑같으면 DOM을 건드리지 않고 숫자(인원/이벤트)만 갱신하도록 고쳐서, 상태가 바뀔 때만 `<img>`가 새로 만들어지게 함.

**위 수정으로도 다 안 끝났음 — 카메라 한 대만 바뀌어도 그리드 전체가 다시 그려짐**: 첫 수정은 "그리드 전체"를 하나의 signature로 묶어서 비교했기 때문에, 카메라 16대 중 단 한 대라도 상태가 바뀌면(다른 캠을 재시작하는 중이라거나) signature가 달라져서 여전히 `innerHTML`을 통째로 다시 그렸다. 그 결과 멀쩡히 재생 중이던 다른 카메라의 `<img>`도 같이 파괴·재연결되길 반복했고, 매번 스트림이 처음(프레임 0)부터 다시 시작되니 사용자에게는 "영상이 뒤로감기한다"처럼 보였다. **위치별로 "c{카메라id}:{상태}" 서명을 따로 비교해서, 바뀐 카드만 `replaceWith`로 교체하고 나머지 카드는 전혀 손대지 않도록 고침** — 다른 카메라 상태를 계속 바꾸면서 모달을 열어둔 채 10초 이상 지켜봐도 끊기지 않는 것까지 확인함.

## 카메라 모달 도구 · 관리 탭 (신규, 전부 동작 검증 완료)

- **카메라 확대 모달에 기간 선택 + 엑셀 다운로드 + 녹화 재생 버튼 추가**: 기간(datetime-local) 지정 후 "엑셀 다운로드"는 `GET /api/v1/zones/{id}/stats/export`로 바로 파일 다운로드, "녹화 재생"은 `GET /api/v1/zones/{id}/playback` 결과(녹화 이력 목록 + 인원 추이 그래프)를 모달 안에 렌더링
- **통계 패널 실시간 갱신(SSE)**: 카메라 모달을 열면 `EventSource`로 `GET /api/v1/zones/{id}/stats/stream`을 구독해 인원·밀집도·체류시간 숫자를 폴링 없이 즉시 갱신, 모달 닫으면 연결 종료
- **"관리" 탭(관리자 전용) 신규**: 현재 선택된 동 소속 구역의 혼잡 임계치(주의·위험 단계)를 표 형태로 한 번에 보고 수정하는 전용 화면. 기존 통계 패널 아코디언의 임계치 입력칸과 같은 API(`GET/PUT /zones/{id}/thresholds`)를 쓰되, 전체 구역을 표로 모아서 보여줌
- 실제 Chrome 헤드리스 브라우저로 로그인→관리 탭→임계치 테이블, 카메라 모달→엑셀 다운로드(실파일 저장 확인)→녹화 재생(결과 렌더링 확인)까지 클릭 테스트 완료

## 아직 안 한 것

- 구역 간 이동 흐름 화살표, 히트맵 토글 (`zone_flows` 집계 로직 자체가 백엔드에 아직 없음)
- 통계 연→월→일→시간 드릴다운 (지금은 최근 10분 1분 단위만)
- 실시간 알림(토스트/푸시) — SSE 연결 자체는 추가됐으나 알림 UI는 아직 숫자 갱신까지만
- "지역 등록수정" 버튼은 자리만 있고 미구현(클릭하면 준비 중 안내만)

## 확정된 스택

- 순수 HTML + JS (빌드 도구 없음) — 빠르게 backend-api와 바로 붙여보기 위함, React 등 새 도구 학습 비용 생략
- 지도: **Google Maps JavaScript API** (처음엔 레퍼런스의 카카오맵 워터마크를 보고 카카오로 갔었는데, 이미 Android 앱용으로 구글 Maps Platform 계정/결제를 설정해둔 상태라 구글로 통일함 — 새 계정 가입 불필요, 같은 프로젝트에서 웹용 키만 추가 발급)
- 차트: Chart.js (CDN으로 바로 사용 가능, 설정 간단)
